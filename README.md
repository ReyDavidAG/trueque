# El Trueque

La tienda interna del grupo: los **cacaos** que ganas participando en [Chispa](https://github.com/ReyDavidAG/chispa) se cambian por servicios y artículos de las empresas, con un cupón canjeable.

Parte del ecosistema **Chispa · El Trueque · [Custodia](https://github.com/ReyDavidAG/custodia)**, que comparte base de datos y personas.

- `propuesta/` · prototipo navegable (`python3 -m http.server 5183`).
- `supabase/` · esquema `trueque` sobre el Supabase de Chispa, semillas y prueba (`cd supabase/tests && npm install --ignore-scripts && npm run check`).
- `docs/database.md` · por qué cada tabla.
- `plan.md` y `state.md` · qué sigue y dónde vamos.

Propuesta personal con datos de ejemplo; no es un sistema oficial.
